### EA-WPR EMA with Recovery ###
Ini adalahh EA script yang mengunakan WWPR indicator dan Ema Cross sebagai acuan membuka posisi open trade.
Feature:
    1. Jika arah harga  berlawanan dengan posisi entry maka EA akan melakukan recovvery dengan averaging (open posisi layar dengan  jarak tertentu/Grid.
    2. Beberapa parameter EA dapat di ataur/sesuaaikan.

Peringatan:
EA ini tidak mmempunyai fitur Stoplost dan MM.
Konfigurasi WPF dan Ema Cross tidak dapat di konfigurasi.
